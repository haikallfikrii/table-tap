# Demo runbook — online & di kedai

Guna selepas lead dari Meta Ads / outreach jawab minat **cuba percuma**.

## Sebelum demo (5 minit)

- [ ] Nama kedai, bandar, ~bilangan meja
- [ ] Peak hours (malam / lunch)
- [ ] Ada printer termal? (Bluetooth / Wi‑Fi)
- [ ] Siapa decide: owner / pengurus
- [ ] Slot 15–20 minit **sebelum** peak

## Demo online (video call)

1. Screen-share `tabletap.my` + login demo / staff order  
2. Tunjuk: QR meja → order customer → skrin dapur/kasir  
3. Tunjuk mark paid + (optional) resit  
4. Tanya: “Bahagian mana paling sakit sekarang — peak order, bil, atau laporan?”  
5. Close: pakej Mula RM29 / Standard RM49 · setup kami bantu  
6. Next step: bayar bulan pertama + hantar menu PDF/foto

## Demo di kedai

1. Bawa 1–2 QR sample + telefon tunjuk dashboard  
2. Letak QR di satu meja, scan bersama owner  
3. Order item test, tunjuk masuk dapur  
4. Elak masa restoran penuh — jangan ganggu staf peak  
5. Close sama; foto menu board jika perlu seed menu

## Objection pendek

| Kata mereka | Jawab |
|-------------|--------|
| Mahal | Banding RM29 vs staf salah order / hilang jualan satu malam |
| Staf tak reti | UI besar; training 15 minit; anda boleh ubah menu dari telefon |
| Nanti dulu | “OK — reply ‘demo’ bila siap. WhatsApp ni kekal.” |
| Ada POS | TableTap fokus order QR + dapur; boleh jalan bersama |
