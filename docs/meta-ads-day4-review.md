# Meta Ads — review hari ke-4

Buka Ads Manager → kampanye `TT_WA_Demo_Nov2026`.

## Angka yang dilihat

| Metric | Nota |
|--------|------|
| Amount spent | Jangan panik kalau &lt; budget harian di awal |
| Conversations / messages | Hasil utama |
| Cost per conversation | Kasar OK: Rp 10rb–50rb awal |
| Results by ad | Bandingkan Ad Duit vs Operasi Peak |

## Keputusan

1. **Satu ad 0 chat, satu ada chat** → pause yang 0 (atau biarkan 2–3 hari lagi jika spend masih kecil).
2. **Kedua ada chat** → biarkan; naik budget hanya jika chat berkualiti (owner/pengurus).
3. **0 chat total** → semak WhatsApp connection, pre-filled message, destinasi WhatsApp only; jangan buru naik budget.
4. **Chat ramai tapi bukan F&B** → ketatkan lokasi / minat; jangan scale dulu.

## Chat berkualiti

- Ada nama kedai + bandar  
- Owner / pengurus  
- Tanya demo atau harga  

Bukan berkualiti: “harga berapa” sekali lalu hilang, atau bukan kedai makan.
