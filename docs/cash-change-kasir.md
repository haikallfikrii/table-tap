# Kasir — kira baki (cash change)

Bila tekan **Tandai lunas** pada order counter/cash, sheet **Bayar tunai** keluar.

## Alur

1. Jumlah perlu bayar dipaparkan  
2. Masukkan duit diterima (atau tekan duit tepat / RM 50 / RM 100)  
3. **Baki** hijau = duit bagi balik; merah = kurang (tak boleh sahkan)  
4. **Sahkan lunas** — atau **Lunas tanpa kira baki** untuk QR/kad  

## Resit

Jika auto-print on, slip tunjuk **Tunai** + **Baki** (tidak disimpan ke DB history).

## Nota

- Split bill belum guna calculator yang sama  
- Cash received tidak masuk laporan closing (UI + print sahaja)
