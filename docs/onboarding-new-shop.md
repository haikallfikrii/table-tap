# Onboarding kedai baru

Checklist selepas deal / bayaran pertama.

## 1. Akaun

- [ ] Cipta shop + package (Mula / Standard / Pro)
- [ ] Owner username + password sementara
- [ ] Kasir / dapur / minuman / waiter mengikut keperluan
- [ ] Tukar password selepas handoff

## 2. Meja & QR

- [ ] Bilangan meja + token unik
- [ ] Cetak stand / tent (kit di `clients/` jika ada)
- [ ] Uji scan 1 meja → order test → nampak di kasir

## 3. Menu

- [ ] Import / key-in menu + harga
- [ ] Foto (optional) ke `storage/uploads`
- [ ] Kategori / stesen (Pro) jika ada dapur berasingan
- [ ] Tanda item habis sekali untuk latih staf

## 4. Printer

- [ ] Chrome/Edge di tablet kasir
- [ ] Pair Bluetooth ESC/POS atau Print Bridge
- [ ] Test print + (optional) drawer
- [ ] Pref: print on paid / hub stesen

## 5. Latihan 15–20 minit

- [ ] Order customer QR
- [ ] Staff order (Grab/Foodpanda)
- [ ] Mark paid + baki tunai (jika ada)
- [ ] Item status dapur
- [ ] Closing / laporan harian (jika Standard+)
