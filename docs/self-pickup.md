# Self-pickup (ambil sendiri)

`fulfillment_mode = self_pickup` pada shop.

## Perilaku

- Customer isi **nama** (wajib)  
- Dapur tanda siap → loceng / alert pickup (ikut setting bunyi)  
- Kasir/waiter boleh mute atau clear pickup alert  
- Berbeza waiter-mode: tiada “hantar ke meja” sebagai flow utama  

## Ops tip

- Letak skrin/TV nampak nama siap  
- Latih staf clear alert supaya bunyi tak berulang tanpa henti  
- Gabungan dengan QR meja tetap OK untuk dine-in hybrid  

Lihat `lp_pf_self_pickup` / setting owner fulfillment.
