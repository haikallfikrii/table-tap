# FAQ owner (BM ringkas)

**Perlu app customer?**  
Tidak — scan QR, guna browser telefon.

**Berapa harga?**  
Mula RM29 / Standard RM49 / Pro RM99 sebulan (semak landing).

**Boleh Grab/Foodpanda?**  
Ya — kasir/waiter key-in sebagai staff order.

**SST?**  
Boleh on/off + rate di setting owner.

**Cancel order?**  
Owner sahaja (kasir tidak).

**Data hilang bila deploy?**  
Menu foto & upload kekal di `storage/`; config di server tidak di-git.

**Demo?**  
Percuma 15–20 minit, online atau di kedai.
