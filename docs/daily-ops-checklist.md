# Daily ops checklist (TableTap business)

Guna setiap hari supaya produk + jualan jalan, dan ada kerja nyata untuk di-commit bila perlu.

## Pagi (10 minit)

- [ ] Semak WhatsApp: lead Ads + kedai live (Big Tree, dll.)
- [ ] Ads Manager: spend semalam, percakapan, creative mana menang
- [ ] Hostinger / tabletap.my load OK? (buka order page 1 meja)

## Petang

- [ ] Balas lead &lt; 1 jam waktu pejabat
- [ ] Demo slot (online / kedai) confirm H−1
- [ ] Nota bug dari kedai → issue singkat atau fail di `docs/`

## Malam (5 minit)

- [ ] Log lead baru (`tools/outreach/ads-lead-log` copy lokal)
- [ ] 1 penambahbaikan kecil: copy Ads, FAQ, tip printer, atau caption Reel
- [ ] Kalau ada perubahan fail → **commit + push `main`** (kerja nyata)

## Jangan

- Commit kosong / “update” tanpa isi hanya untuk kotak hijau  
- Deploy `production` tanpa niat go-live
