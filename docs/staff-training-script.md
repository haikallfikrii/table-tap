# Skrip latihan staf (15 minit)

## Kasir

1. Login kasir  
2. Bunyi + connect printer  
3. Order masuk dari QR → tandai status / lunas  
4. Staff order untuk Grab (popup)  
5. Baki tunai bila customer bayar cash  
6. Laporan harian / closing (jika ada akses)  

## Dapur / minuman

1. Login stesen  
2. Skrin besar — item menunggu → masak → siap  
3. Jangan tutup tab; biarkan poll hidup  

## Waiter

1. Pickup / hantar  
2. Jangan cancel order (owner sahaja)  

## Owner

1. Menu: harga, habis, foto  
2. User staf  
3. Setting SST / jam buka  
4. History + cancel bila perlu
