# Meta Ads — WhatsApp demo (Nov 2026)

Playbook for TableTap lead gen via Instagram/Facebook Reels → WhatsApp.

## Campaign

| Field | Value |
|-------|--------|
| Name | `TT_WA_Demo_Nov2026` |
| Objective (new Ads Manager) | **Interaksi** → ad set destination **WhatsApp** |
| Daily budget | **Rp 100.000** (~RM 25) |
| Bid | Highest volume / maximize conversations |
| Duration (batch 1) | 10 days, review day 4 & 10 |
| Account top-up (batch 1) | **Rp 1.200.000 – 1.500.000** |

Do **not** use Traffic or “boost post for likes”. Auto budget 2× boost: leave **off**.

## Ad set

- Destination: **manual → WhatsApp only** (`+60 11-2535 2270`)
- Turn off Messenger / Instagram DM for this test (one inbox)
- Geo: Perlis, Kedah, Penang, Perak
- Age: 28–55
- Placements: Advantage+ OK (incl. WhatsApp Status)
- Two ads in the **same** ad set (let Meta pick the winner):
  1. `TT_Ad_Duit_*` — money/ops pain (kira kertas, pager)
  2. `TT_WA_Operasi_Peak` — peak/chaos ops

## Creative notes

- Prefer existing IG Reels (9:16) with end card “Jom pakai TableTap · RM29/bulan”
- CTA: **Send WhatsApp message**
- Pre-filled customer message (≤80 chars):

```text
Minat demo TableTap. Prefer: online / di kedai. Kedai: ___ Bandar: ___
```

- Welcome (auto after tap):

```text
Waalaikumussalam. Terima kasih. Saya Haikal dari TableTap. Demo percuma 15–20 minit, online atau di kedai. Boleh bagi nama kedai, bandar, dan lebih kurang berapa meja?
```

## Reply script (manual)

1. Confirm online vs on-site demo  
2. Ask meja count + peak hours  
3. Book 15–20 min slot (before busy service)  
4. Close on Mula RM29 / Standard RM49  

## Kill / scale rules

- Day 4: pause the weaker creative if spend is lopsided with zero chats  
- Scale to Rp 150.000/day only after quality chats (owner/manager, real shop)  
- Pause if 4 days with zero WhatsApp opens after delivery is confirmed OK
