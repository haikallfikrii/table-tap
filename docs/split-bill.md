# Split bill (kasir)

Untuk order dine-in / takeaway unpaid dengan **lebih dari 1 item**.

## Alur

1. Tekan **Split bill** pada kad order  
2. Pilih qty item untuk bil tetamu A (nama optional)  
3. Confirm → sebahagian jadi order lunas baharu; baki kekal di order asal  
4. Auto-print resit bil yang dipecah (jika pref on)  

## Nota

- Delivery tidak support split  
- Calculator baki tunai belum digabung ke flow split  
- `split_from_order_id` kekal untuk jejak di resit
