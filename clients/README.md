# Client kits

Print-ready QR table designs, invoices, and assets for TableTap shops.

## Big Tree Western (`big-tree-western/`)

- Kangar, Perlis · Pro features at Standard price · 26 tables (1 bonus)
- Design variants A–J (A5 / tent / sticker)
- Print helpers: A4 cut sheet, A5 sheets
- Per-table QR PNGs in `qr/`
- Invoices: setup (September) + monthly (e.g. Oktober 2026)

Open `index.html` in a browser to preview and switch tables.

## Port Santai DHighway (`port-santai-dhighway/`)

- Harbor / highway-themed A6 designs
- Colour variants + red/black layouts
- QR pack and table artwork under `QR Codes/` and `Tables/`

## Adding a new client

1. Copy an existing kit folder as a starting point.
2. Generate unique table tokens from the live shop (do not reuse another client’s QR).
3. Keep invoices and payment QR under that client folder.
4. Do not commit raw WhatsApp menu photo dumps — use curated `reco/` or `assets/` images instead.
