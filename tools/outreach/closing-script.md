# Closing script selepas demo

## Soft close

```text
Dari apa kita tengok tadi, bahagian ___ paling tolong kedai anda.
Nak mula dengan pakej Mula RM29 atau Standard RM49?
Setup meja + menu saya bantu — bulan pertama + setup, terus boleh go-live.
```

## Ask for pay

```text
Baik — saya hantar invois / QR bayaran. Lepas bayar, hantar screenshot, hari yang sama kita aktifkan akaun.
```

## If hesitate

```text
Tak apa. Saya tinggal ringkasan pakej. Bila ready, reply “aktif” — slot setup saya buka.
```
