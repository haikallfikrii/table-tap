# Tools

Small local helpers for TableTap ops and sales. Open HTML files directly in a browser (`file://` is fine).

## Outreach

| File | Use |
|------|-----|
| `outreach/wa-mesej.html` | One-click WhatsApp pitch template. Fill kedai, menu highlight, your name & phone, then copy. |
| `outreach/wa-balasan-demo.md` | Reply scripts for Meta Ads WhatsApp demo leads (online / di kedai). |
| `outreach/wa-quick-replies.txt` | Short WhatsApp Business quick-reply labels. |
| `outreach/ads-lead-log.template.csv` | Empty CSV columns for logging ad chats. |
| `outreach/follow-up-drip.md` | H0–H7 follow-up messages for ad leads. |
| `outreach/objection-handling.md` | Short objection replies in BM. |
| `outreach/demo-confirm-templates.md` | Confirm + reminder templates for booked demos. |
| `outreach/first-message-variants.md` | Cold/warm first WhatsApp message variants. |
| `outreach/closing-script.md` | Soft-close script after a live demo. |
| `outreach/post-demo-summary.md` | WA summary to send after a demo. |

Do **not** store prospect phone lists in this repo. Keep CSVs with numbers only on your machine (see root `.gitignore` → `leads/`).
